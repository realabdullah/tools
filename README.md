# Tools

A small set of developer tools that run in your browser.

## What's inside

- **JSON**: browse, search, repair and reshape a document, or compare two.
- **JWT**: decode a token, verify its signature, or build and sign a new one.
- **Base64**: encode and decode text, files and data URIs.

## How to use it

Paste something on the home page and Tools opens the right tool for it. Press
`⌘K` (or `Ctrl+K`) to jump to any tool.

## Privacy

Everything runs in your browser. Nothing you paste leaves the tab. There are no
accounts and no tracking.

## Getting started

```bash
pnpm install
pnpm dev
```
